Firefox Codex MCP — Linux x86_64

English instructions: README.md. Korean translation: README.ko.md and INSTALL.ko.txt.

Requirements: ordinary Firefox 140+ and the local Codex app or CLI.
Rust, Node, pairing codes, tokens and profile paths are not needed.
Windows has a separate preview. macOS, Snap/Flatpak Firefox and Android are not validated.

First installation
1. Open Codex and check that you can sign in. Install ordinary desktop Firefox.
2. Fully extract the downloaded archive. Do not run setup from inside the archive.
   Open a terminal in the extracted folder and run:
   ./install.sh
   A file manager that supports running scripts can also launch install.sh directly.
   If it opens in an editor, use the terminal command above. No administrator rights are needed.
3. In the Firefox setup page, choose Install connection, then Continue.
   The installer registers MCP and installs the browser skill and guidance automatically.
   You do not need to install the skill separately or edit configuration files.
4. Choose Add Codex Work Tabs to Firefox in the same setup page.
   Confirm Firefox's Continue Installation/Allow and Add prompts.
   The package includes Mozilla-signed codex-work-tabs-0.4.1.xpi.
   The *-unsigned.xpi is for development/review only; see SIGNING.md.
5. Open a new Codex chat and try:
   Open https://example.com in the browser, click Learn more, and tell me the destination page title.
   A new Firefox work tab and a successful link click confirm the connection.
   Review any tool approval request for the web task you asked for.

If something goes wrong
- Script opens in an editor: run ./install.sh from a terminal in the extracted folder.
- Codex is not found: check your Codex app/CLI installation, then reopen setup.
- Settings are registered but tools are missing: reopen Codex and start a new chat.
- Extension is paused: open its button in the Firefox you want to use and choose Resume.
- Tool approval is denied: use the approval process allowed by your administrator.
  Setup never changes approval policy. Non-interactive codex exec has different
  approval behavior; first try the Codex app or interactive CLI.

Step-by-step guide: docs/first-install-linux.md

In the same chat, work tabs continue across turns. Access ends after 24 hours without
a request, explicit revocation, pause or a Firefox/helper restart. Result tabs stay open.

A single connected Firefox profile is selected automatically. With several profiles,
choose Use this Firefox in the intended profile. An offline selected profile never
silently falls back to another. If the selected profile is not Firefox's default,
you may need to open that profile yourself.

Update: run install.sh from the newer package and choose Update connection.
Firefox stays open. Previous work-tab access is revoked; start a new chat afterwards.
To update the extension, install the new signed XPI through Firefox's Add-ons Manager.
Direct-distribution XPIs do not currently have an automatic update channel.

Remove: open Firefox Codex Manager and choose Remove connection.
Remove the extension separately in Firefox Add-ons Manager.
Firefox profiles, logins, result tabs and user changes are preserved.
Close existing Codex chats to end their already-running tool connections.

./install.sh --install
./install.sh --update
./install.sh --doctor
./install.sh --uninstall
./install.sh --repair

Advanced BiDi: ./install.sh --install-bidi [ABSOLUTE_PROFILE_PATH]
Only this mode may require saving your work and reopening Firefox with
Firefox (Codex connection). Debugging options end on the next normal Firefox restart.

Installation receipts and recovery: ~/.local/state/firefox-codex-mcp/
Run --repair after an interrupted installation. Modified files are not overwritten.
Local Codex chats can use this profile's website logins in their own work tabs.
Existing tabs and other chats' tabs are never adopted. See PRIVACY.md.
SHA256SUMS checks download integrity. See LICENSE and the build provenance.
