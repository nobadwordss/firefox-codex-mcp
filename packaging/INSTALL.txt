Firefox Codex MCP 0.2.0 — Linux x86_64

필요한 것: 일반 Linux Firefox, 로컬 Codex 앱 또는 CLI.
사용자는 Rust, Node.js, 확장 프로그램, 토큰을 설치하거나 입력할 필요가 없습니다.
배포 CI 패키지: Ubuntu 22.04(glibc 2.35) 이상. Windows/macOS 미지원.
Snap/Flatpak 프로필은 탐지하지만 샌드박스 실행은 아직 지원 검증하지 않았습니다.

처음 설치
1. 압축을 풀고 install.sh 실행. 파일 관리자가 실행하지 않으면 그 폴더에서
   터미널을 열어 ./install.sh 입력. 관리자 권한/sudo는 사용하지 않습니다.
2. 관리 화면에서 Firefox 프로필 확인 → 설치 → 진행.
3. 일반 모드 Firefox가 켜져 있다면 작업을 저장한 후 종료하고, 앱 메뉴의
   Firefox (Codex 연결)로 한 번 다시 엽니다. 새 Codex 채팅에서 웹 작업을 요청하세요.
   도구가 안 보이면 Codex 앱을 다시 여세요. 기존 탭/로그인은 유지됩니다.

다음 사용: Firefox가 꺼져 있으면 AI가 작업 요청 시 자동 실행합니다.
평소에는 Firefox (Codex 연결) 실행기를 사용하세요.
일반 Firefox 실행기로 먼저 켰다면 다시 시작이 필요합니다.

업데이트
새 배포 패키지를 내려받아 풀고 install.sh → 업데이트 → 진행.
실행 중인 Firefox/채팅은 종료하지 않습니다. 기존 채팅은 이전 코드로 남으므로
Firefox 도구를 쓰던 채팅을 종료하고 10초 뒤 새 채팅에서 작업하세요.
이전 패키지로 되돌릴 때도 같은 방법입니다. 먼저 작업 중인 채팅을 종료하세요.

연결 진단 / 제거
앱 메뉴의 Firefox Codex 관리에서 연결 진단 또는 제거를 선택하세요.
제거는 이 도구의 전역 MCP·지침·스킬·실행기·설정 블록만 대상으로 합니다.
사용자가 수정한 파일, Firefox 프로필·로그인·기존 탭은 보존합니다.
이미 실행 중인 채팅은 직접 종료해야 기존 연결도 끝납니다.
Firefox 디버깅 옵션은 브라우저를 정상 종료하고 일반 실행기로 다시 열 때 해제됩니다.
remote.prefs.recommended=false 값이 prefs.js에 남을 수 있습니다. 이는 자동화의
권장 테스트 설정 적용을 막는 값이며, 제거 시 prefs.js 전체를 덮어쓰지 않습니다.

명령행 사용
./install.sh --install [프로필 절대 경로]
./install.sh --update
./install.sh --doctor
./install.sh --uninstall
./install.sh --repair

설치 장부/복구 정보: ~/.local/state/firefox-codex-mcp/
설정 충돌 또는 중단된 설치: --repair. 외부에서 바뀐 파일은 자동 덮어쓰지 않습니다.
복구가 실패하면 transaction.json을 보존하고 충돌 파일을 확인하세요.
이전 개발 설치는 새 패키지를 한 번 설치한 뒤 제거할 수 있습니다.

주의: 이는 같은 사용자 권한의 도구입니다. 기존 로그인으로 새 탭을 열 수 있습니다.
채팅 간 탭 분리는 MCP 도구의 논리적 경계이며 OS 보안 격리가 아닙니다.
프로젝트/관리자 설정이 전역 등록을 덮어쓸 수 있습니다. 클라우드 채팅에는 적용 안 됩니다.
브로커 강제 종료(SIGKILL) 후 세션 점유 오류가 남으면 Firefox 작업 저장 후 다시 여세요.
iframe, 파일 업로드, 네이티브 입력 등은 아직 지원하지 않습니다.

SHA256SUMS는 전송 손상 확인용이며 배포자 서명이 아닙니다.
공개 GitHub CI에서 생성된 증명이 있는 패키지는 gh attestation verify로 별도 확인하세요.
