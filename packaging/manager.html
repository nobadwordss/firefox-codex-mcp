1. Install the connection

Registers Codex connection settings and browser-use guidance for this account. No configuration file editing is needed.

Local Codex chats on this account can open work tabs using your normal Firefox's website logins. Existing tabs are not imported.

For everyday settings, open Codex Work Tabs in Firefox and choose Settings. No separate application or Firefox profile is created. To update, open setup from a newer package. Firefox stays open. Updating the connection revokes previous work-tab access; start a new chat afterwards.

Program updates and removal

Your system software manager owns this program. Install a newer RPM or DEB to update it; there is no automatic update repository yet. Updates release previous work-tab access, so start a new Codex chat afterwards.

To uninstall completely, choose Disconnect Codex above for each connected account, then remove firefox-codex-mcp with your software manager. Remove Codex Work Tabs separately in Firefox if desired. Removing the package stops its helpers, but leaves each account's connection settings for that user to clean up or reuse.

2. Add the Firefox extension

After installing the connection, add the signed extension to the Firefox you want to use. It connects automatically without a code, token or profile path.

Add Codex Work Tabs to Firefox

Open this page in Firefox and choose the link above. The extension is signed by Mozilla. In Firefox's installation prompts, choose Continue Installation or Allow, then Add.

3. Try a new Codex chat

After adding the extension, open a new Codex chat and try this request:

Open https://example.com in the browser, click Learn more, and tell me the destination page title.

A new Firefox work tab and a successful link click confirm the connection. Registered settings alone do not prove that browser control is ready.

Review any tool approval request for the web task you asked for. If the tools are missing, reopen Codex and start a new chat. If the extension is paused, open its button in the Firefox you want to use and choose Resume.
