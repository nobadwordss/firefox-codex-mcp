Connect Firefox to Codex

Set up once. In a new chat, Codex can open and use its own work tabs.

Checking installation…

1. Install the connection

Installs the Codex connection settings and browser-use guidance automatically. No configuration file editing is needed.

Local Codex chats on this account can open work tabs using the selected Firefox profile's website logins. Existing tabs are not imported.

To update, open setup from a newer package. Firefox stays open. Updating the connection revokes previous work-tab access; start a new chat afterwards.

2. Add the Firefox extension

After installing the connection, add the signed extension to the Firefox you want to use. It connects automatically without a code, token or profile path.

Add Codex Work Tabs to Firefox

Open this page in Firefox and choose the link above. The extension is signed by Mozilla. In Firefox's installation prompts, choose Continue Installation or Allow, then Add.
Advanced: use BiDi debugging instead of the extensionBiDi may require a Firefox restart. The extension connection does not use this profile selector.

3. Try a new Codex chat

After adding the extension, open a new Codex chat and try this request:

Open https://example.com in the browser, click Learn more, and tell me the destination page title.

A new Firefox work tab and a successful link click confirm the connection. Registered settings alone do not prove that browser control is ready.

Review any tool approval request for the web task you asked for. If the tools are missing, reopen Codex and start a new chat. If the extension is paused, open its button in the Firefox you want to use and choose Resume.
