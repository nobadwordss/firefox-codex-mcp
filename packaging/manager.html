Firefox를 Codex에 연결하세요

한 번 설정하면, 새 채팅에서 AI가 작업 탭을 직접 열어 사용합니다.

확인 중…

1. 연결 프로그램 설치

이 컴퓨터의 모든 로컬 Codex 채팅이 선택한 Firefox의 로그인 상태로 새 작업 탭을 만들 수 있습니다. 기존 탭을 자동으로 가져오지는 않습니다.

업데이트: 새 패키지에서 이 화면을 다시 열면 됩니다. Firefox를 종료하지 않습니다. 확장 연결 갱신 시 이전 작업 탭 접근은 해제되며 새 채팅에서 다시 시작합니다.

2. Firefox 확장 추가

연결 프로그램을 설치한 뒤 사용할 Firefox에 서명된 확장을 추가하세요. 프로필은 확장이 자동으로 찾습니다. 코드나 토큰을 입력하지 않습니다.

Firefox에 Codex Work Tabs 확장 추가

이 화면을 Firefox에서 열어 위 링크를 누르세요. Mozilla가 서명한 확장입니다. 주소창 아래의 ‘설치 계속’ 또는 ‘허용’을 누른 뒤 권한 안내에서 ‘추가’를 누르세요.
고급: 확장 대신 BiDi 디버깅 사용BiDi는 Firefox 재시작이 필요할 수 있습니다. 확장 방식에는 이 선택을 사용하지 않습니다.
