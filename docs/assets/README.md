# Cursor icon

The approved direction is the user's compact, rounded, **tail-less** arrow cursor:
black fill, white outline, transparent background. No enclosing circle or long stem.

The built-in image generation tool produced a visual study from the user's reference.
The final repo-native SVG reconstructs its simple silhouette with smooth paths so the
16–128 px extension assets have clean edges. `cursor.svg` is the editable source.
PNG files in `extension/icons` are size exports of this SVG.

Prompt used for the visual study: "Recreate the reference's compact black rounded
triangular cursor pointing upper-left, with a small inward notch on the lower-right
side, a slim white outline and actual transparent background. No protruding tail,
shaft, stem, circle, badge, text, glow or shadow. Keep its compact proportions."
