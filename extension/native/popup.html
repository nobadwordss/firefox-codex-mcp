코드·토큰·프로필 경로 입력은 필요 없습니다. 이 컴퓨터의 Codex 채팅은 이 프로필의 로그인 상태로 웹사이트에 접근할 수 있습니다. Codex가 만든 탭만 제어하며 원래 열려 있던 탭은 가져오지 않습니다.

같은 채팅에서는 다음 메시지에도 작업 탭을 이어 씁니다. 24시간 사용하지 않거나 접근 해제·중지·Firefox 재시작 시 제어권이 해제됩니다. 결과 탭은 닫지 않습니다.

연결이 안 되나요?

처음 한 번 로컬 연결 프로그램을 설치하세요. 확장만 설치했다면 배포 패키지의 install.sh를 실행하세요. 여러 Firefox 중 선택한 프로필이 꺼지면 다른 프로필로 자동 이동하지 않습니다.

프로필을 복사해 연결이 충돌한 경우에만 아래 버튼을 누른 뒤 ‘이 Firefox 사용’을 선택하세요.
